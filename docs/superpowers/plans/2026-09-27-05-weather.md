**Goal:** Fetch Open-Meteo hourly weather at the Tri-County Gun Club for every event date, summarize each
event's 10:00–12:00 window into `event_weather` (recompute step 20), and cache next Sunday's forecast. All of it
runs as Postgres-queue jobs that do nothing when `weather_enabled` is false.

**Architecture:** `weather/client.py` is the only code that makes HTTP calls. It uses httpx, asks Open-Meteo
for UTC unix timestamps, and converts them to America/Los_Angeles wall-clock hours with `zoneinfo`.
The `weather_sync` job (`weather/sync.py`) finds event dates whose window hours are missing and fetches them:
one archive-API request per calendar year for dates older than 6 days, and one forecast-API `past_days` request
for anything newer. It upserts `weather_hourly` and enqueues `recompute` when a window row was inserted or changed.
`weather/aggregate.py` is pure, and `analytics/steps/s20_event_weather.py` uses it to rebuild `event_weather` on
every pipeline run. The `forecast_refresh` job (`weather/forecast.py`) stores next Sunday's hours in
`forecast_cache`. Database access is SQLAlchemy Core over `Base.metadata.tables["<C4 table>"]`, because C4 names
tables and columns but not ORM classes.

**Tech Stack:** Python 3.13 · httpx · respx (tests) · SQLAlchemy 2 Core with
`sqlalchemy.dialects.postgresql.insert(...).on_conflict_do_update` · pydantic `TypeAdapter` · `zoneinfo` +
tzdata · pytest on the Plan 01 T1 `session` fixture (Postgres 17 via testcontainers or `TEST_DATABASE_URL`) ·
Open-Meteo archive API `https://archive-api.open-meteo.com/v1/archive` and forecast API
`https://api.open-meteo.com/v1/forecast` (no API key).

## Review Focus
None of the master's five Review Focus items belongs to Plan 05. Plan 03 owns items 1, 2 and 5 (Plan 08 shares
item 1), Plan 02 owns item 3, and Plans 06 and 09 own item 4. The five below are specific to this plan, most likely
first. Each one's test sits in the task that owns the code.
1. **Winter and DST hours.** Open-Meteo's `timezone=America/Los_Angeles` applies one fixed UTC offset to a whole
   response (verified 2026-09-27: a January 2026 request came back as GMT-7, so 09:00 PST was labelled "10:00"). If
   the client relied on it, every PST event would be summarized an hour early. The client therefore requests UTC
   unixtime and converts each stamp. On the autumn change, the repeated 01:00 keeps its first occurrence, so the
   `ts_local` primary key never collides. Task 1: `test_winter_timestamps_use_standard_time_offset`,
   `test_fall_back_repeated_local_hour_keeps_first`.
2. **Open-Meteo down, rate-limited, or returning a malformed or wrong-unit body partway through a sync.** The
   expected behaviour is a `WeatherApiError` with a readable message and no partial year written. The job then fails
   and C6 retries it with backoff. Task 1: `test_http_error_reason_surfaces`,
   `test_http_error_without_json_body_shows_text`, `test_invalid_json_on_success_is_rejected`,
   `test_transport_error_is_wrapped`, `test_unexpected_units_are_rejected`. Task 2:
   `test_open_meteo_failure_writes_nothing`.
3. **Null hours from archive lag.** Recent Sundays can come back with nulls. Those hours are not stored, the event
   gets no `event_weather` row (never zeros), and the next run fetches it again. Task 2:
   `test_rows_with_missing_values_are_not_stored`. Task 3: `test_null_needed_value_skips_event`,
   `test_s20_skips_event_with_missing_window_row`.
4. **Precipitation at exactly the 0.02 in threshold after float32 storage.** C4 types `weather_hourly`'s
   measurements as `real` (float4), and Plan 03 T1 makes `event_weather`'s measurements `REAL` too (C4 leaves their
   type open). psycopg's default text protocol reads a stored 0.01 back as 0.01, but a binary-format read or a SQL
   cast to double precision returns 0.009999999776482582 (verified on Postgres 17, Decisions §11). The window must be
   labelled `rain` either way. Task 3: `test_float32_noise_does_not_flip_rain_threshold`, plus the chain test, which goes
   through a real `real` column round-trip. Other plans that threshold `event_weather.precip_in` are a blocking
   cross-plan item (Decisions §11).
5. **Forecast data standing in for observations.** Recent events use forecast-API rows, which must be replaced by
   archive rows once the date is more than 6 days old. Next-Sunday forecasts must never enter `weather_hourly`.
   Task 2: `test_forecast_rows_upgraded_to_archive_after_six_days`. Task 4:
   `test_forecast_refresh_does_not_touch_weather_hourly`.

## Decisions
Choices made where the master is silent, listed so cross-plan auditors can check them.
1. **Club coordinates are 45.3525, -122.8082** (Task 1 sets the C2 `club_lat`/`club_lon` defaults to these; C2
   allows Plan 05 T1 exactly this change). Evidence gathered 2026-09-27:
   - OpenStreetMap way 1480976223 "Tri County Gun Club" has its centroid at 45.3524879, -122.8081643 and a
     bounding box of lat 45.3463–45.3583, lon -122.8113 to -122.8054.
   - The FFL listing puts the club at 45.35002, -122.80739, 0.28 km from that centroid.
   - The club's own site (tcgc.org) gives the address as **13050** SW Tonquin Rd, Suite 200, Sherwood OR 97140.
     The master's original "12500 SW Tonquin Rd" was wrong, and the US Census geocoder finds no match for 12500.
     For 13050 it returns 45.35132, -122.81320, an interpolated point on the Tonquin Rd frontage 0.41 km west of the
     chosen point.
   - The old default (45.3565, -122.8228) is 1.22 km west-northwest, outside the property. Both points map to the
     same archive grid cell (45.377853, -122.816895), but the forecast API's cell differs (45.3636, -122.8282
     against 45.3378, -122.8178).
2. **UTC in, local out.** Requests send `timeformat=unixtime` and no `timezone`. `parse_hourly` converts each stamp
   with `zoneinfo`, and `ts_local` is naive local wall-clock time. On the autumn DST change the first 01:00 wins.
3. **Variables and units.** Hourly `temperature_2m, apparent_temperature, precipitation, rain, wind_speed_10m,
   wind_gusts_10m, wind_direction_10m, cloud_cover, relative_humidity_2m, pressure_msl, weather_code` map to
   `temp_f, apparent_f, precip_in, rain_in, wind_mph, gust_mph, wind_dir_deg, cloud_pct, humidity_pct,
   pressure_hpa, weather_code`. Pressure is sea-level (`pressure_msl`), as in public reports. The client sends
   `temperature_unit=fahrenheit&wind_speed_unit=mph&precipitation_unit=inch` and rejects a body whose
   `hourly_units` are not °F / `mp/h` / `inch` / `hPa`.
4. **Open-Meteo URL settings.** `open_meteo_archive_url` and `open_meteo_forecast_url` are full endpoint URLs, used
   verbatim. C2 gives them no default. This plan requires Plan 01 T1's defaults to be
   `https://archive-api.open-meteo.com/v1/archive` and `https://api.open-meteo.com/v1/forecast`, and Task 1's
   `test_default_settings_query_open_meteo_at_the_club` fails otherwise. A different choice needs a C2 amendment,
   not a Plan 05 edit. **Cross-plan requirement for the controller and critic:** C2 does not state this, so it
   rests on Plan 01. As checked on 2026-09-27, Plan 01's Decisions §7 and its Task 1 `Settings` code already set
   exactly these two defaults (and `app_version = "dev"`). Any change there must go through the controller and keep
   this requirement. The Plan 05 tests never rely on an `app_version` default, because C2 does not give one: they
   pass `app_version` (or set `APP_VERSION`) themselves.
5. **Table access by name.** Code reaches `events`, `weather_hourly`, `event_weather`, `forecast_cache`, `jobs`,
   `imports` and `import_score_rows` through `sunday_clays.models.Base.metadata.tables["<name>"]` (SQLAlchemy Core)
   with C4 column names, because every access is a bulk select, a bulk insert or an `ON CONFLICT` upsert. Plan 03 T1
   also maps these tables to ORM classes (`Event`, `WeatherHourly`, `EventWeather`, `ForecastCache`, `Job`, `Import`,
   `ImportScoreRow`; Plan 03 Decisions §1). Importing `sunday_clays.models` registers every table on
   `Base.metadata` (Plan 03 T1's `models/__init__.py` re-exports all models), so a lookup never misses.
6. **What `weather_hourly` holds.** Only local hours that fall on event dates are stored: never whole years, and
   never next-Sunday forecasts. A row is stored only when all nine aggregated fields (`temp_f, apparent_f,
   precip_in, wind_mph, gust_mph, wind_dir_deg, cloud_pct, humidity_pct, pressure_hpa`) are non-null; `rain_in` and
   `weather_code` may be null. The upsert writes a row only when it is new or its measured values or `source` are
   `IS DISTINCT FROM` the stored row. `fetched_at` is the aware "now" of the sync that last inserted or changed the
   row: an unchanged row keeps its earlier `fetched_at`.
7. **Which dates are synced.**
   - Eligible dates are `events.event_date` values whose window has closed, meaning local time has reached 13:00 on
     that date.
   - A date needs fetching when any of its 10:00, 11:00 or 12:00 rows is missing, or when it is more than 6 days old
     and any window row has source `forecast` (the row is upgraded to archive).
   - Dates more than 6 days old use the archive API, one request per calendar year, with UTC `start_date` = the
     first needed date and `end_date` = the last needed date + 1 day.
   - Newer dates use a single forecast request, `past_days=7&forecast_days=1`, stored with source `forecast`.
8. **All or nothing per sync.** Every fetch finishes before the first upsert, so an Open-Meteo failure partway
   through writes nothing. `recompute` is enqueued (dedupe key `recompute`, C6) only when at least one 10:00, 11:00
   or 12:00 row was inserted or changed (§6), so a sync that fetches identical values enqueues nothing.
9. **Job payloads are ignored.** `weather_sync` derives its dates from `events`, and `forecast_refresh` derives its
   target from the clock. Each handler checks `get_settings().weather_enabled` itself and returns before any HTTP
   call or write. Plan 03 T7's worker (`process_one`) already completes both kinds as no-ops when weather is disabled
   (Plan 03 Decisions §17), so the handler's own guard covers direct calls: the handler tests, the Task 3 chain test
   and any future caller.
10. **Aggregation rounding.** Temperature, apparent temperature, wind, gust, cloud, humidity and pressure are
    rounded to 1 dp, precipitation to 3 dp, and wind direction to whole degrees in `[0, 360)`. The condition is
    chosen from the rounded values. A calm window (zero resultant vector) gets `wind_dir_deg = NULL` but the row is
    still written. A null in any value the C7 rules need is treated as a missing row. `event_weather.source` is
    `forecast` if any window row came from the forecast API, else `archive`. Step s20 deletes and re-inserts every
    `event_weather` row on each run.
11. **Blocking cross-plan item for the controller and the cross-plan critic: float32 precipitation threshold.** It
    blocks Plan 06 T1 and Plan 10 T3, and Plan 03 T1 if option (a) below is chosen. It does not block Plan 05. C4
    types `weather_hourly`'s measurements as `real` but gives `event_weather`'s measurement columns no type; Plan 03
    T1's `EventWeather` model and `0001_initial` make all nine of them `REAL` (float4). C7 requires the precip band,
    the `rain` condition and the `rain`/`mudder` achievements to share one threshold, precipitation ≥ 0.02 in. Three
    consumer lines compare the value they read back to 0.02 without rounding (named by function, because line numbers
    move as plans are edited):
    - Plan 06 T1 `frames.precip_band` in `2026-09-27-06-analytics-core.md`:
      `return "wet" if precip_in >= WET_PRECIP_IN else "dry"`.
    - Plan 10 T3 `_masks` (the `rain` entry) in `2026-09-27-10-achievements-stations.md`:
      `"rain": _num(rounds["precip_in"]) >= RAIN_IN,`.
    - Plan 10 T3 `_mudder`, same file: `(rounds["score"] >= MUDDER_SCORE) & (_num(rounds["precip_in"])
      >= RAIN_IN)`.

    What those lines receive was checked on 2026-09-27 against `postgres:17` with SQLAlchemy 2 and psycopg 3:
    - A stored 0.02 reads back as exactly `0.02` through psycopg's default text protocol, because Postgres 12 and
      later print float4 as the shortest string that round-trips. That covers Plan 06's `_ROUNDS_SQL`/`_EVENTS_SQL`
      and `pd.read_sql`.
    - It reads back as `0.019999999552965164` through a binary-format cursor, an explicit `::float8` cast or `avg()`.
      The window's `condition` is then `rain`, but the band says `dry` and no `rain` or `mudder` trophy is awarded.

    The consumers as written are therefore correct today, but only because of a driver and SQL detail that no
    contract states. The exact-threshold case is realistic. Open-Meteo reports precipitation in 0.004 in steps, the
    recorded fixture contains a literal 0.02 hour, and window sums of exactly 0.020 occur. Only precipitation is
    exposed: the temperature, gust and cloud thresholds (35, 40, 55, 70, 85 °F; 10, 20 mph; 30, 75 %) are integers,
    which float4 represents exactly. Resolve the item one of two ways:
    - (a) Preferred: Plan 03 T1 declares the nine `event_weather` measurement columns `double precision`
      (`DOUBLE_PRECISION`) in `models/weather.py` and `0001_initial` before that task merges. C4 leaves these types
      open, so no contract amendment is needed. This plan's cross-plan interface audit sent the change to the
      controller as a producer request against Plan 03 T1. With `double precision`, a stored 0.02 reads back as
      exactly `0.02` through the text protocol, a `::float8` cast and `avg()` alike (verified on `postgres:17`,
      2026-09-27). `weather_hourly` stays `real`, as C4 says: Plan 05 rounds every aggregate before storing it.
    - (b) Plan 06 T1 `precip_band` compares `round(precip_in, 3) >= WET_PRECIP_IN`, and Plan 10 T3 `rain`/`mudder`
      compare `_num(rounds["precip_in"]).round(3) >= RAIN_IN`. Each change gets a test that feeds
      `0.019999999552965164` and expects `wet` or an award.

    This plan edits neither Plan 03 nor those plans, and none of its code or tests depends on the choice: its tests
    compare stored floats with `pytest.approx` or with values that float4 and float8 both hold exactly. Until the
    controller records a choice, Task 3's Produces states the rule consumers must follow; under (a) the rule still holds
    and costs nothing. Plan 05's own labelling already rounds before comparing (§10;
    `test_float32_noise_does_not_flip_rain_threshold`).
12. **Forecast cache.**
    - Payload shape: `{"target_date": "YYYY-MM-DD", "hours": [<HourlyObs as JSON>, ...]}`, holding every local hour
      of the target date. One row per target date, upserted; old rows are kept.
    - The target is today while a Sunday event is still ahead or running (local time before 12:00), otherwise the
      coming Sunday.
    - The request is `past_days=0&forecast_days=<days ahead + 2>`.
    - A response with no hours on the target date, or whose 10:00–12:00 window lacks a value the aggregation reads,
      raises `WeatherApiError` and leaves the previous row untouched: `forecast_cache` is overwritten only when the
      fetched window is complete.
    - Consumers (Plan 11 T1) call `load_forecast`, then `aggregate_window(target_date, stored.hours)`, and key caches
      on `fetched_at` (C7).
13. **Shared files with other plans.** `backend/src/sunday_clays/weather/__init__.py` is created empty by Task 1 and
    by no other plan: Plan 03 T7's `load_handlers()` imports `sunday_clays.weather` only once
    `importlib.util.find_spec` finds it (Plan 03 Decisions §17). The one file outside `weather/` and `analytics/steps/`
    that this plan edits is Plan 01 T1's `backend/tests/unit/test_config.py`: Task 1 changes the two coordinate
    asserts of `test_defaults_match_the_contract`, because that test pins the C2 defaults Task 1 replaces.
14. **Test layout.** Test modules have unique basenames (`test_weather_*`, `test_s20_*`, `test_forecast_*`) and
    keep their helpers inside the module, with no shared conftest, so Tasks 2 and 4 touch disjoint files.
    - No `__init__.py` goes into `tests/unit/weather/` or `tests/integration/weather/`. Plan 01 T1 runs pytest with
      `--import-mode=importlib` (Plan 01 Decisions §13), and the test directories of Plans 01 and 03 carry no
      `__init__.py` either. Only Plan 02's `tests/unit/ingest/` is a package, for its relative helper imports.
    - Tests never call the naive `datetime(...)` constructor. Plan 01 T1's ruff config selects `DTZ`, whose `DTZ001`
      rejects it, so naive local wall-clock hours are written `datetime.combine(date(...), time(h))`, as in Plan 02
      D20. Aware datetimes (`datetime(..., tzinfo=LA)`) are fine.
    - The code blocks are wrapped at 88 columns; Plan 01's `line-length = 100` makes `ruff format .` (the first
      command of each full-suite step) re-wrap them. That is expected and changes no behaviour.
15. **Chain-test wiring.** The Task 3 chain test gets its handlers from `sunday_clays.jobs.handlers.load_handlers()`

16. **Handler settings in tests.** Handler tests build real `Settings` from C2 environment variables (the four

```python
def test_winter_timestamps_use_standard_time_offset() -> None:
    # 18:00Z-20:00Z on 2026-01-04 are 10:00-12:00 PST (UTC-8), not PDT (UTC-7)
    stamps = [utc_stamp(2026, 1, 4, h) for h in (18, 19, 20)]
    body = body_for(stamps)
    rows = parse_hourly(body, LA)
    assert [row.ts_local for row in rows] == [
        datetime.combine(date(2026, 1, 4), time(10)),
        datetime.combine(date(2026, 1, 4), time(11)),
        datetime.combine(date(2026, 1, 4), time(12)),
    ]


def test_fall_back_repeated_local_hour_keeps_first() -> None:
```

```python
"""Open-Meteo archive and forecast client for the club's hourly weather.

Every request asks for UTC unix timestamps, and this module converts them to
America/Los_Angeles wall-clock hours. Open-Meteo's own ``timezone=`` option applies one
fixed UTC offset to a whole response, so a January date fetched in September would come
back labelled an hour late.
"""

from __future__ import annotations

from collections.abc import Mapping
from dataclasses import dataclass
from datetime import UTC, date, datetime
from types import TracebackType
from typing import Any, Final, Protocol, Self
from zoneinfo import ZoneInfo

import httpx

from sunday_clays.config import Settings

WINDOW_HOURS: Final[tuple[int, ...]] = (10, 11, 12)
"""Local hourly stamps of the 10:00-12:00 event window (C7)."""

HOURLY_VARIABLES: Final[tuple[str, ...]] = (
    "temperature_2m",
    "apparent_temperature",
    "precipitation",
    "rain",
    "wind_speed_10m",
    "wind_gusts_10m",
    "wind_direction_10m",
    "cloud_cover",
    "relative_humidity_2m",
    "pressure_msl",
    "weather_code",
)
EXPECTED_UNITS: Final[Mapping[str, str]] = {
    "temperature_2m": "°F",
    "apparent_temperature": "°F",
    "precipitation": "inch",
    "rain": "inch",
    "wind_speed_10m": "mp/h",
    "wind_gusts_10m": "mp/h",
    "pressure_msl": "hPa",
}
REQUEST_OPTIONS: Final[Mapping[str, str]] = {
    "temperature_unit": "fahrenheit",
    "wind_speed_unit": "mph",
    "precipitation_unit": "inch",
    "timeformat": "unixtime",
}
USER_AGENT: Final = "sunday-clays/1 (+https://sundayclays.claysmasher.com)"
TIMEOUT_S: Final = 30.0


class WeatherApiError(Exception):
    """Open-Meteo was unreachable or answered with something this client cannot use."""


@dataclass(frozen=True)
class HourlyObs:
    """One local hour of weather; fields match the ``weather_hourly`` columns (C4)."""

    ts_local: datetime
    temp_f: float | None
    apparent_f: float | None
    precip_in: float | None
    rain_in: float | None
    wind_mph: float | None
    gust_mph: float | None
    wind_dir_deg: float | None
    cloud_pct: float | None
    humidity_pct: float | None
    pressure_hpa: float | None
    weather_code: int | None


class HourlySource(Protocol):
    """What the weather jobs need from a provider (``OpenMeteoClient`` in prod)."""

    def archive(self, start: date, end: date) -> list[HourlyObs]: ...

    def forecast(self, *, past_days: int, forecast_days: int) -> list[HourlyObs]: ...


def _number(value: Any) -> float | None:
    return None if value is None else float(value)


def _code(value: Any) -> int | None:
    return None if value is None else int(value)


def parse_hourly(payload: Any, tz: ZoneInfo) -> list[HourlyObs]:
    """Turn an Open-Meteo ``timeformat=unixtime`` body into local wall-clock hours.

    Rows are sorted by ``ts_local`` with one row per local hour: on the autumn DST
    change the repeated 01:00 keeps its first (daylight-time) occurrence.
    """
    try:
        units = payload["hourly_units"]
        hourly = payload["hourly"]
        stamps = list(hourly["time"])
        columns = {name: list(hourly[name]) for name in HOURLY_VARIABLES}
        wrong = {
            n: units.get(n)
            for n, unit in EXPECTED_UNITS.items()
            if units.get(n) != unit
        }
    except (KeyError, TypeError, AttributeError) as exc:
        raise WeatherApiError(f"Open-Meteo response is malformed: {exc!r}") from exc
    if wrong:
        raise WeatherApiError(f"Open-Meteo returned unexpected units {wrong}")
    if any(len(values) != len(stamps) for values in columns.values()):
        raise WeatherApiError("Open-Meteo hourly arrays have different lengths")
    rows: dict[datetime, HourlyObs] = {}
    try:
        for i, stamp in enumerate(stamps):
            aware = datetime.fromtimestamp(int(stamp), UTC).astimezone(tz)
            ts_local = aware.replace(tzinfo=None, fold=0)
            if ts_local in rows:
                continue
            rows[ts_local] = HourlyObs(
                ts_local=ts_local,
                temp_f=_number(columns["temperature_2m"][i]),
                apparent_f=_number(columns["apparent_temperature"][i]),
                precip_in=_number(columns["precipitation"][i]),
                rain_in=_number(columns["rain"][i]),
                wind_mph=_number(columns["wind_speed_10m"][i]),
                gust_mph=_number(columns["wind_gusts_10m"][i]),
                wind_dir_deg=_number(columns["wind_direction_10m"][i]),
                cloud_pct=_number(columns["cloud_cover"][i]),
                humidity_pct=_number(columns["relative_humidity_2m"][i]),
                pressure_hpa=_number(columns["pressure_msl"][i]),
                weather_code=_code(columns["weather_code"][i]),
            )
    except (TypeError, ValueError, OverflowError) as exc:
        raise WeatherApiError("Open-Meteo returned a non-numeric hourly value") from exc
    return sorted(rows.values(), key=lambda row: row.ts_local)


def _reason(response: httpx.Response) -> str:
    try:
        body = response.json()
    except ValueError:
        body = None
    if isinstance(body, dict) and isinstance(body.get("reason"), str):
        return str(body["reason"])
    return response.text[:200]


class OpenMeteoClient:
    """Blocking Open-Meteo client for one location; use it as a context manager."""

    def __init__(
        self,
        *,
        archive_url: str,
        forecast_url: str,
        lat: float,
        lon: float,
        timezone: str,
    ) -> None:
        self._archive_url = archive_url
        self._forecast_url = forecast_url
        self._location = {"latitude": str(lat), "longitude": str(lon)}
        self._tz = ZoneInfo(timezone)
        self._http = httpx.Client(timeout=TIMEOUT_S, headers={"User-Agent": USER_AGENT})

    @classmethod
    def from_settings(cls, settings: Settings) -> Self:
        return cls(
            archive_url=settings.open_meteo_archive_url,
            forecast_url=settings.open_meteo_forecast_url,
            lat=settings.club_lat,
            lon=settings.club_lon,
            timezone=settings.timezone,
        )

    def __enter__(self) -> Self:
        return self

    def __exit__(
        self,
        exc_type: type[BaseException] | None,
        exc: BaseException | None,
        tb: TracebackType | None,
    ) -> None:
        self._http.close()

    def archive(self, start: date, end: date) -> list[HourlyObs]:
        """Every hour of the UTC days ``start``..``end`` (inclusive), archive API."""
        window = {"start_date": start.isoformat(), "end_date": end.isoformat()}
        return self._get(self._archive_url, window)

    def forecast(self, *, past_days: int, forecast_days: int) -> list[HourlyObs]:
        """Hours from ``past_days`` UTC days back to ``forecast_days`` days ahead."""
        window = {"past_days": str(past_days), "forecast_days": str(forecast_days)}
        return self._get(self._forecast_url, window)

    def _get(self, url: str, window: Mapping[str, str]) -> list[HourlyObs]:
        params = {
            **self._location,
            **window,
            "hourly": ",".join(HOURLY_VARIABLES),
            **REQUEST_OPTIONS,
        }
        try:
            response = self._http.get(url, params=params)
        except httpx.HTTPError as exc:
            raise WeatherApiError(
                f"Open-Meteo request failed: {type(exc).__name__}"
            ) from exc
        if response.status_code != httpx.codes.OK:
            raise WeatherApiError(
                f"Open-Meteo HTTP {response.status_code}: {_reason(response)}"
            )
        try:
            body = response.json()
        except ValueError as exc:
            raise WeatherApiError("Open-Meteo returned invalid JSON") from exc
        return parse_hourly(body, self._tz)
```

```python
class FakeSource:
    """Stands in for Open-Meteo (external) and records every request the sync makes.

    Like the real API it returns more hours than asked for (neighbouring days)."""

    def __init__(self, hours: list[HourlyObs], fail_on_archive_call: int = 0) -> None:
        self.hours = hours
        self.fail_on_archive_call = fail_on_archive_call
        self.archive_calls: list[tuple[date, date]] = []
        self.forecast_calls: list[tuple[int, int]] = []

    def archive(self, start: date, end: date) -> list[HourlyObs]:
        self.archive_calls.append((start, end))
        if len(self.archive_calls) == self.fail_on_archive_call:
            raise WeatherApiError("Open-Meteo HTTP 503: busy")
        return list(self.hours)

    def forecast(self, *, past_days: int, forecast_days: int) -> list[HourlyObs]:
        self.forecast_calls.append((past_days, forecast_days))
        return list(self.hours)
```

```python
"""``weather_sync`` job: fetch missing event-window weather into ``weather_hourly``."""

from __future__ import annotations

from collections.abc import Sequence
from dataclasses import dataclass
from datetime import date, datetime, time, timedelta
from itertools import groupby
from typing import Any, Final
from zoneinfo import ZoneInfo

from sqlalchemy import Table, select
from sqlalchemy.dialects.postgresql import insert as pg_insert
from sqlalchemy.orm import Session

from sunday_clays.config import get_settings
from sunday_clays.jobs.handlers import handler
from sunday_clays.jobs.queue import enqueue
from sunday_clays.models import Base
from sunday_clays.weather.client import (
    WINDOW_HOURS,
    HourlyObs,
    HourlySource,
    OpenMeteoClient,
)

ARCHIVE_MIN_AGE_DAYS: Final = 7  # "older than 6 days" -> archive API
FORECAST_PAST_DAYS: Final = 7
FORECAST_DAYS: Final = 1
WINDOW_CLOSED_HOUR: Final = 13  # an event date is fetched once local time reaches 13:00
UPSERT_CHUNK: Final = 1000
REQUIRED_FIELDS: Final[tuple[str, ...]] = (
    "temp_f",
    "apparent_f",
    "precip_in",
    "wind_mph",
    "gust_mph",
    "wind_dir_deg",
    "cloud_pct",
    "humidity_pct",
    "pressure_hpa",
)
MEASURED_COLUMNS: Final[tuple[str, ...]] = (*REQUIRED_FIELDS, "rain_in", "weather_code")


@dataclass(frozen=True)
class SyncResult:
    fetched_dates: tuple[date, ...]
    rows_upserted: int
    window_rows_upserted: int
    recompute_job_id: int | None


def _table(name: str) -> Table:
    return Base.metadata.tables[name]


def _archive_before(now_local: datetime) -> date:
    """Event dates strictly before this day are older than 6 days: archive API."""
    return now_local.date() - timedelta(days=ARCHIVE_MIN_AGE_DAYS - 1)


def dates_needing_weather(session: Session, now_local: datetime) -> list[date]:
    """Event dates whose 10:00/11:00/12:00 rows are missing, or still forecast-sourced
    although the date is older than 6 days. ``now_local`` is timezone-aware."""
    events = _table("events")
    hourly = _table("weather_hourly")
    today = now_local.date()
    last = today if now_local.hour >= WINDOW_CLOSED_HOUR else today - timedelta(days=1)
    dates: list[date] = list(
        session.scalars(
            select(events.c.event_date)
            .where(events.c.event_date <= last)
            .order_by(events.c.event_date)
        ).all()
    )
    stamps = [datetime.combine(d, time(h)) for d in dates for h in WINDOW_HOURS]
    sources: dict[date, list[str]] = {d: [] for d in dates}
    found = session.execute(
        select(hourly.c.ts_local, hourly.c.source).where(hourly.c.ts_local.in_(stamps))
    )
    for ts_local, source in found:
        sources[ts_local.date()].append(source)
    archive_before = _archive_before(now_local)
    return [
        d
        for d, got in sources.items()
        if len(got) < len(WINDOW_HOURS) or (d < archive_before and "forecast" in got)
    ]


def _is_complete(obs: HourlyObs) -> bool:
    return all(getattr(obs, name) is not None for name in REQUIRED_FIELDS)


def upsert_hourly(
    session: Session, rows: Sequence[tuple[HourlyObs, str]], *, fetched_at: datetime
) -> int:
    """Insert or overwrite ``weather_hourly`` rows keyed by ``ts_local``."""
    table = _table("weather_hourly")
    values = [
        {
            "ts_local": obs.ts_local,
            **{name: getattr(obs, name) for name in MEASURED_COLUMNS},
            "source": source,
            "fetched_at": fetched_at,
        }
        for obs, source in rows
    ]
    for start in range(0, len(values), UPSERT_CHUNK):
        stmt = pg_insert(table).values(values[start : start + UPSERT_CHUNK])
        updated = {name: stmt.excluded[name] for name in (*MEASURED_COLUMNS, "source")}
        stmt = stmt.on_conflict_do_update(
            index_elements=[table.c.ts_local],
            set_={**updated, "fetched_at": stmt.excluded.fetched_at},
        )
        session.execute(stmt)
    return len(values)


def sync_weather(
    session: Session, source: HourlySource, *, now_local: datetime
) -> SyncResult:
    """Fetch every missing event date, then upsert (a failed fetch writes nothing)."""
    needed = dates_needing_weather(session, now_local)
    archive_before = _archive_before(now_local)
    fetched: list[tuple[HourlyObs, str]] = []
    old = [d for d in needed if d < archive_before]
    for _year, group in groupby(old, key=lambda d: d.year):
        chunk = list(group)
        wanted = set(chunk)
        hours = source.archive(chunk[0], chunk[-1] + timedelta(days=1))
        fetched += [(obs, "archive") for obs in hours if obs.ts_local.date() in wanted]
    recent = {d for d in needed if d >= archive_before}
    if recent:
        hours = source.forecast(
            past_days=FORECAST_PAST_DAYS, forecast_days=FORECAST_DAYS
        )
        fetched += [(obs, "forecast") for obs in hours if obs.ts_local.date() in recent]
    complete = [(obs, src) for obs, src in fetched if _is_complete(obs)]
    upserted = upsert_hourly(session, complete, fetched_at=now_local)
    window = sum(1 for obs, _ in complete if obs.ts_local.hour in WINDOW_HOURS)
    job_id = enqueue(session, "recompute", dedupe_key="recompute") if window else None
    return SyncResult(tuple(needed), upserted, window, job_id)


@handler("weather_sync")
def weather_sync_handler(session: Session, payload: dict[str, Any]) -> None:
    """Job entry point; the payload is ignored (dates always come from ``events``)."""
    settings = get_settings()
    if not settings.weather_enabled:
        return
    now_local = datetime.now(ZoneInfo(settings.timezone))
    with OpenMeteoClient.from_settings(settings) as client:
        sync_weather(session, client, now_local=now_local)
```

### Task 3: Event-window aggregation and recompute step 20 (master Plan 05 T3)

**Context:** Every pipeline run (C6 step order `20 event_weather`) rebuilds `event_weather` (C4) from
`weather_hourly`. The C7 per-field rules use the 10:00, 11:00 and 12:00 local rows:
- **Means of the three rows:** `temp_f`, `apparent_f`, `wind_mph`, `cloud_pct`, `humidity_pct`, `pressure_hpa`.
- **`wind_dir_deg`:** the speed-weighted circular mean of the same three rows.
- **`precip_in`:** the SUM of the 11:00 and 12:00 rows, because Open-Meteo precipitation is a preceding-hour sum.
- **`gust_mph`:** the MAX of the 11:00 and 12:00 rows (preceding-hour maximum).
- **Missing data:** an event with a missing needed row gets no row.
- **Condition label, in order:** `rain` if precip ≥ 0.02 in; `windy` if gust ≥ 20; `overcast` if cloud ≥ 75%;
  `partly_cloudy` if cloud ≥ 30%; else `clear`.

The float32 `real` columns make rounding necessary before any threshold is applied (Decisions §10). The chain test
proves that the rebuild handler (Plan 03 T4), this plan's `weather_sync` handler (Task 2) and the `recompute` handler
(Plan 03 T7) connect end to end.

```python
"""Event-window weather (C7): the 10:00, 11:00 and 12:00 local rows -> one summary.

Values are rounded (1 dp; precipitation 3 dp; direction to whole degrees) before
the condition label is chosen, so float32 storage noise (a ``real`` 0.01 read in binary
format or cast to double precision is 0.0099999998) never moves a value across a threshold.
"""

from __future__ import annotations

import math
from collections.abc import Iterable, Sequence
from dataclasses import dataclass
from datetime import date
from statistics import fmean
from typing import Final

from sunday_clays.weather.client import WINDOW_HOURS, HourlyObs

ACCUMULATION_HOURS: Final[tuple[int, ...]] = (11, 12)  # preceding-hour sums/maxima
RAIN_IN: Final = 0.02
WINDY_GUST_MPH: Final = 20.0
OVERCAST_PCT: Final = 75.0
PARTLY_CLOUDY_PCT: Final = 30.0


@dataclass(frozen=True)
class WindowWeather:
    """One event's window summary; fields match the ``event_weather`` columns (C4)."""

    temp_f: float
    apparent_f: float
    precip_in: float
    wind_mph: float
    gust_mph: float
    wind_dir_deg: float | None
    cloud_pct: float
    humidity_pct: float
    pressure_hpa: float
    condition: str


class _IncompleteWindowError(Exception):
    pass


def condition_label(*, precip_in: float, gust_mph: float, cloud_pct: float) -> str:
    """C7 rule order: rain, windy, overcast, partly_cloudy, clear."""
    if precip_in >= RAIN_IN:
        return "rain"
    if gust_mph >= WINDY_GUST_MPH:
        return "windy"
    if cloud_pct >= OVERCAST_PCT:
        return "overcast"
    if cloud_pct >= PARTLY_CLOUDY_PCT:
        return "partly_cloudy"
    return "clear"


def circular_mean_deg(
    directions: Sequence[float], speeds: Sequence[float]
) -> float | None:
    """Speed-weighted mean compass direction in whole degrees; None when calm."""
    east = sum(
        s * math.sin(math.radians(d)) for d, s in zip(directions, speeds, strict=True)
    )
    north = sum(
        s * math.cos(math.radians(d)) for d, s in zip(directions, speeds, strict=True)
    )
    if math.hypot(east, north) < 1e-9:
        return None
    return float(round(math.degrees(math.atan2(east, north))) % 360)


def _need(values: Sequence[float | None]) -> list[float]:
    present = [v for v in values if v is not None]
    if len(present) != len(values):
        raise _IncompleteWindowError
    return present


def aggregate_window(
    event_date: date, hours: Iterable[HourlyObs]
) -> WindowWeather | None:
    """The event's window summary; None when a needed row or value is missing."""
    by_hour = {
        obs.ts_local.hour: obs
        for obs in hours
        if obs.ts_local.date() == event_date and obs.ts_local.hour in WINDOW_HOURS
    }
    if len(by_hour) < len(WINDOW_HOURS):
        return None
    window = [by_hour[h] for h in WINDOW_HOURS]
    late = [by_hour[h] for h in ACCUMULATION_HOURS]
    try:
        temp = _need([o.temp_f for o in window])
        apparent = _need([o.apparent_f for o in window])
        wind = _need([o.wind_mph for o in window])
        direction = _need([o.wind_dir_deg for o in window])
        cloud = _need([o.cloud_pct for o in window])
        humidity = _need([o.humidity_pct for o in window])
        pressure = _need([o.pressure_hpa for o in window])
        precip = _need([o.precip_in for o in late])
        gust = _need([o.gust_mph for o in late])
    except _IncompleteWindowError:
        return None
    precip_in = round(sum(precip), 3)
    gust_mph = round(max(gust), 1)
    cloud_pct = round(fmean(cloud), 1)
    return WindowWeather(
        temp_f=round(fmean(temp), 1),
        apparent_f=round(fmean(apparent), 1),
        precip_in=precip_in,
        wind_mph=round(fmean(wind), 1),
        gust_mph=gust_mph,
        wind_dir_deg=circular_mean_deg(direction, wind),
        cloud_pct=cloud_pct,
        humidity_pct=round(fmean(humidity), 1),
        pressure_hpa=round(fmean(pressure), 1),
        condition=condition_label(
            precip_in=precip_in, gust_mph=gust_mph, cloud_pct=cloud_pct
        ),
    )
```

```python
    if values:
```

```python
"""``forecast_refresh`` job: next Sunday's hourly forecast into ``forecast_cache``.

The payload is ``{"target_date": "YYYY-MM-DD", "hours": [HourlyObs as JSON, ...]}``
holding every local hour of the target date. Consumers summarize the event window
with ``weather.aggregate.aggregate_window(target_date, stored.hours)`` and key any
cache on ``fetched_at`` (C7). Forecast hours never enter ``weather_hourly``.
"""

from __future__ import annotations

from dataclasses import dataclass
from datetime import date, datetime, timedelta
from typing import Any, Final
from zoneinfo import ZoneInfo

from pydantic import TypeAdapter
from sqlalchemy import select
from sqlalchemy.dialects.postgresql import insert as pg_insert
from sqlalchemy.orm import Session

from sunday_clays.config import get_settings
from sunday_clays.jobs.handlers import handler
from sunday_clays.models import Base
from sunday_clays.weather.client import (
    HourlyObs,
    HourlySource,
    OpenMeteoClient,
    WeatherApiError,
)

SUNDAY: Final = 6
EVENT_END_HOUR: Final = 12
_HOURS: Final = TypeAdapter(list[HourlyObs])


@dataclass(frozen=True)
class StoredForecast:
    target_date: date
    hours: tuple[HourlyObs, ...]
    fetched_at: datetime


def next_event_sunday(now_local: datetime) -> date:
    """Today while a Sunday event is still ahead or running (before 12:00), else the
    coming Sunday."""
    today = now_local.date()
    if today.weekday() == SUNDAY and now_local.hour < EVENT_END_HOUR:
        return today
    return today + timedelta(days=(SUNDAY - today.weekday()) % 7 or 7)


def refresh_forecast(
    session: Session, source: HourlySource, *, now_local: datetime
) -> date:
    """Fetch and upsert the forecast for the next event Sunday; returns that date.

    ``forecast_days`` covers the target's last local hour (UTC runs up to a day ahead).
    With no hours for the target the previous cached row is kept and the job fails.
    """
    target = next_event_sunday(now_local)
    days_ahead = (target - now_local.date()).days
    fetched = source.forecast(past_days=0, forecast_days=days_ahead + 2)
    hours = [obs for obs in fetched if obs.ts_local.date() == target]
    if not hours:
        raise WeatherApiError(
            f"Open-Meteo forecast has no hours for {target.isoformat()}"
        )
    table = Base.metadata.tables["forecast_cache"]
    payload = {
        "target_date": target.isoformat(),
        "hours": _HOURS.dump_python(hours, mode="json"),
    }
    stmt = pg_insert(table).values(
        target_date=target, payload=payload, fetched_at=now_local
    )
    session.execute(
        stmt.on_conflict_do_update(
            index_elements=[table.c.target_date],
            set_={
                "payload": stmt.excluded.payload,
                "fetched_at": stmt.excluded.fetched_at,
            },
        )
    )
    return target


def load_forecast(session: Session, target_date: date) -> StoredForecast | None:
    """The cached forecast for ``target_date``, or None when none was fetched."""
    table = Base.metadata.tables["forecast_cache"]
    row = session.execute(
        select(table.c.payload, table.c.fetched_at).where(
            table.c.target_date == target_date
        )
    ).one_or_none()
    if row is None:
        return None
    hours = _HOURS.validate_python(row.payload["hours"])
    return StoredForecast(
        target_date=target_date, hours=tuple(hours), fetched_at=row.fetched_at
    )


@handler("forecast_refresh")
def forecast_refresh_handler(session: Session, payload: dict[str, Any]) -> None:
    """Job entry point; the payload is ignored (the clock picks the target date)."""
    settings = get_settings()
    if not settings.weather_enabled:
        return
    now_local = datetime.now(ZoneInfo(settings.timezone))
    with OpenMeteoClient.from_settings(settings) as client:
        refresh_forecast(session, client, now_local=now_local)
```
